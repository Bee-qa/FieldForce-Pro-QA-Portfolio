# FieldForce Pro – Manual QA Testing Portfolio

## Project Overview

FieldForce Pro is a field workforce management application designed for Australian BG Engineering Pty Ltd (ABG).

The application supports the management of customers, projects, jobs, field engineer assignments, attendance, job completion, timesheets, leave requests, approvals, and operational reporting.

This repository demonstrates an end-to-end manual software testing approach, covering requirement analysis, test planning, test design, test execution, defect management, and requirements traceability.

----------------------------------------------------------------

## QA Portfolio Objectives

The purpose of this project is to demonstrate practical manual testing activities across the Software Testing Life Cycle (STLC), including:

- Requirement analysis and review
- User story and acceptance criteria analysis
- Test planning
- Test scenario design
- Detailed test case design
- Positive and negative testing
- Functional and permission-based testing
- Test data preparation
- Test execution
- Defect identification and reporting
- Retesting and regression testing
- Requirements traceability
- Test execution reporting
