# Restful Booker – Manual API Test Plan

## 1. Project Overview

Restful Booker is a public REST API used in this portfolio to demonstrate practical manual API testing using Postman.

The API provides booking management functionality including authentication, retrieving bookings, creating bookings, updating bookings, partially updating bookings, and deleting bookings.

## 2. Testing Objective

The objective of this testing is to validate the behaviour, reliability, and error handling of the Restful Booker API through manual API testing.

Testing will validate:

- HTTP request methods
- HTTP status codes
- Request headers
- Request and response payloads
- Path and query parameters
- Authentication
- Positive and negative scenarios
- CRUD operations
- API error handling
- Data consistency between API operations

## 3. Tool

Postman – Manual API request execution and response validation.

## 4. API Under Test

Application: Restful Booker  
API Type: REST  
Data Format: JSON  
Environment: Public test environment
