## Application Modules

The FieldForce Pro application contains the following modules:

- Login
- Dashboard
- Customers
- Projects
- Jobs
- Attendance
- Timesheets
- Leave
- Reports

----------

## User Roles

| Role | Responsibilities |
|------|------------------|
| Office Staff | Create customers, projects and jobs |
| Supervisor | Assign jobs and approve completed work |
| Field Engineer | Complete assigned jobs, mark attendance and submit timesheets |
